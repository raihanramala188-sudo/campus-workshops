# Campus Workshops

A multi-page static website built with semantic HTML and CSS for the Campus Workshops lab, featuring a #75003b crimson theme, dedicated workshop pages, and a contact page with form validation and a :target confirmation state.

## Project Structure

- `index.html` — Main landing page and workshop overview
- `contact.html` — Contact form with validation and `:target` confirmation state
- `css/site.css` — Shared styles and #75003b crimson theme
- `workshops/`
  - `web-type.html` — Web typography workshop page
  - `sensor-stories.html` — Sensor stories workshop page
  - `accessible-forms.html` — Accessible forms workshop page

## Local Preview

Open `index.html` directly in any web browser (or serve the `campus-workshops` folder with a local static server).
